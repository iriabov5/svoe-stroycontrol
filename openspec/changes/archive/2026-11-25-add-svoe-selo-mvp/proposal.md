# Предложение: автономный MVP «Своё Село»

## Why
Нужен доступный без банковского аккаунта сервис проверки участка, планирования стройки, контроля ипотечных обязательств и демонстрационного оформления страховки. Текущий СтройКонтроль требует Docker и серверной авторизации; новый MVP должен работать автономно.

## What Changes
- Добавить независимое приложение `mvp/`: React, TypeScript, Vite, Tailwind CSS, Lucide, локальные шрифты и ресурсы.
- Реализовать `/`, `/estimate`, `/mortgage-care`, `/insurance` по предоставленному ТЗ, с русским интерфейсом и адаптивностью 375–1440 px.
- Использовать модель поэтапного строительства СтройКонтроля как основу сметы; не изменять существующие `frontend/`, `backend/`, REST-контракт и серверные права доступа.
- Добавить мягкую демоавторизацию, перенос гостевых данных, продолжение прерванного действия и localStorage.
- Все проверки кадастра, вход через ЕСИА, заявки и оплата явно демонстрационные. Не отправлять документы, телефоны и заявки внешним сервисам.
- Добавить запуск без Docker и проверку ключевых сценариев.

## Impact
Новая клиентская функциональность не меняет REST API исходного продукта. Данные MVP хранятся отдельно от серверной базы. Существующая серверная авторизация остаётся неизменной. Предложение не включает настоящие банковские интеграции, SMS, оплату и проверку документов.
