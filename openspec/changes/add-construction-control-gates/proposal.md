# Контрольные точки строительства

## Цель

Помочь заказчику и подрядчику не пропустить действия перед необратимыми работами:
заливкой фундамента, закрытием инженерных сетей и передачей дома.

## Объём первой итерации

- Показывать на карточке проекта блок «Контрольные точки» только для участников проекта.
- Рассчитывать три карточки из уже имеющихся этапов, журнала, приёмки и состояния проекта:
  «Перед заливкой фундамента», «Перед закрытием инженерных сетей», «Перед передачей дома».
- Для каждой карточки показывать ответственного, причину, следующий шаг и ссылку на
  существующий экран этапа, журнала или приёмки.
- Добавить синтетические демонстрационные проекты: один для заказчика и один для подрядчика.

## Вне объёма

- Автоматическая техническая экспертиза, юридическая приёмка и подтверждение соответствия нормам.
- Новая роль технадзора, новые загрузки файлов, платежи и промышленный банковский обмен.
- Блокировка выполнения работ: первая итерация только информирует и ведёт к действию.

## Ценность

Заказчик видит, что проверить до скрытия результата работ. Подрядчик видит, какие
подтверждения и чьё решение требуются для следующего шага без отдельного звонка.

## Предложение

В дальнейшем можно добавить настраиваемые контрольные точки по технологии дома и
отдельную роль технического специалиста.

## Предлагаемая итерация 2: живая демо-карточка и действия

- Добавить к проекту необязательный «паспорт дома»: площадь, этажность, конструкцию,
  фундамент, кровлю и плановый срок. Поля создаются пустыми для существующих и новых
  обычных объектов; заполненный паспорт появляется только у демо-проектов.
- В демо-истории фундамента и инженерных сетей показывать безопасные синтетические
  иллюстрации работ в существующем журнале этапа. Они служат для просмотра сценария,
  не являются доказательством качества работ.
- Пометить в списке этапов и на карточке проекта работы, для которых сейчас нужно
  действие участника: ответить на вопрос, опубликовать подтверждение или проверить
  результат до следующей необратимой работы.
- В шапке кабинета вывести текстовый индикатор «Есть действия» с числом текущих
  контрольных точек. Он ведёт к первому объекту, где действие требуется текущей роли.

## Вне объёма итерации 2

- Push-, email- и SMS-уведомления, отдельный центр уведомлений и сохранение статуса
  прочтения.
- Распознавание качества работ по фотографии, проверка строительных норм и блокировка
  переходов этапа.
- Редактирование паспорта дома в пользовательском интерфейсе: в этой итерации он
  служит реалистичным демонстрационным контекстом и API-основой для следующей формы.
