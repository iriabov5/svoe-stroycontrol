# Разработка

Откройте `../Запустить.command` двойным щелчком. Скрипт использует локальный Node из соседней папки it-championship-runtime или Node из PATH. При отсутствии зависимостей выполняет npm ci.

Ручной запуск из mvp: `npm ci`, затем `npm run dev`. Адрес http://127.0.0.1:5173. Оставьте терминал открытым; Ctrl+C останавливает сервер. Сборка: `npm run build`, просмотр сборки: `npm run preview` при свободном порте 5173.

При ошибке доступа повторите запуск. Если порт занят, скрипт не завершает чужие процессы. Данные localhost и 127.0.0.1 хранятся раздельно: используйте один адрес.

Бизнес-правила: src/domain.ts; сохранение и авторизация: src/store.tsx; страницы: Home, Estimate, MortgageCare, Insurance. Серверная часть исходного проекта не изменена.
