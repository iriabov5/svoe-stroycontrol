# Проверки

`npm test`: расчёты и даты, перенос гостевых данных, продолжение экспорта после SMS, отмена входа, проверка участка, загрузка и одобрение документов, покупка страховки и обработка переполнения localStorage.

`npm run build`: строгая проверка TypeScript и production-сборка Vite.

В Chrome проверены страницы на ширине 375 и 1440 пикселей. Снимок мобильного календаря находится в screenshots. Эти проверки не заменяют проверку реальных банковских интеграций: в MVP они демонстрационные.
