# Проход контрольных точек — 27 ноября 2026

Проверяющий — Codex (ИИ), представители ролей не участвовали. Проверка начинается со списка объектов под синтетическим аккаунтом: цель заказчика — найти и проверить сдачу, цель подрядчика — опубликовать подтверждение и снять требование действия. Начальный переход выполняется через видимый индикатор, без предварительного открытия прямого URL этапа. Автоматизированный проход дополнен просмотром полных снимков; он не заменяет обратную связь пользователей.

| Экран и шаг | Наблюдение и влияние | Исправление / проверка |
|---|---|---|
| Паспорт дома, чтение характеристик | Подписи источников были соседними p внутри dl; axe-core обнаружил нарушение структуры списка определений | Источник помещён внутрь dd; повторный axe-проход проверяет структуру |
| Переход к журналу из точки | Заголовок страницы перехватывал фокус у целевой секции; пользователь клавиатуры терял результат перехода | Переход ждёт загрузки секции, переносит фокус после эффектов страницы; браузерный тест проверяет фактический фокус |
| Завершённое фото-подтверждение | После публикации главная карточка переключается на ожидание приёмки всего дома; результат завершённой точки доступен в «Все контрольные точки» | В пошаговом сценарии и снимке раскрывается список всех точек; завершённая публикация не выдаётся за приёмку |
| Завершённая точка на телефоне | Контраст ссылки на подсвеченной поверхности был 4,04:1, ниже 4,5:1 | У ссылки задан более тёмный цвет; повторный мобильный axe-проход проверяет контраст |
| Пересчёт точек во время действий | При смене кнопки действия на обычную ссылку общая анимация цвета оставляла промежуточный фон и текст с недостаточным контрастом | Для ссылок контрольных точек отключён переход цвета; повторный axe-проход проверяет обновления |
| История после завершения дома | Ссылка точки этапа ошибочно указывала на секцию завершения внутри экрана этапа | Завершённая точка этапа ведёт к его приёмке; HANDOVER ведёт к завершению карточки |
| Смена ролей в сквозном тесте | Немедленная навигация после нажатия выхода могла оборвать запрос завершения сессии | Тест ждёт видимую форму входа перед сменой аккаунта; бизнес-код выхода не менялся |

Обзор объекта, паспорт и подрядчик используют общую адаптивную сетку; на телефоне карточки идут последовательно. Основное действие соответствует персональному canAct сервера, этапы сохраняют отдельные идентичности, статусы объясняются текстом. Проверяются клавиатурный фокус, доступность axe-core и отсутствие горизонтального переполнения.
