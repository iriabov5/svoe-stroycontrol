# Демонстрация контрольных точек

После запуска Compose создайте изолированные синтетические данные:

```sh
./scripts/seed-control-gates-demo.sh
```

Скрипт выводит два email и единый пароль. Заказчик увидит «Дом семьи Орловых»: паспорт
дома 128 м², фундамент со статусом ожидания его проверки и журнал с иллюстрацией
армирования. Подрядчик увидит «Каркасный дом на Озёрной»: паспорт объекта, инженерные
сети с действием по публикации подтверждений и фото примера вводов. В обоих кабинетах
в шапке появляется ссылка `! 1 действие`, а требующий действия этап выделен в плане.

Иллюстрации — синтетические демонстрационные примеры, а не доказательство качества
реальных работ. Скрипт временно переводит только созданные синтетические карточки в
режим `LEGACY`, чтобы создать этапы через публичный API; рабочие данные не изменяются.

В объекте заказчика журнал фундамента содержит запись подрядчика, демонстрационное
фото и открытый вопрос, который ждёт ответа заказчика. В объекте подрядчика журнал
инженерных сетей содержит фото проложенных трасс и следующее подтверждение.
